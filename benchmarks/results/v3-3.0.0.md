# HeatStressR v3 workload validation

Measured 2026-10-06 on Ubuntu 24.04.5, Intel Core i9-13900HK,
R 4.6.1, heatindex 0.0.2, Rcpp 1.1.2. Single process; median of three runs,
with garbage collection outside timed sections. These synthetic observations
exercise warm states with varying humidity and instantaneous solar forcing.
Hardware and runtime differences limit comparisons to other published timings.

Reproduce canonical workloads:

```sh
V3_ROWS=10000,100000 BENCH_REPS=3 Rscript benchmarks/benchmark-v3.R
```

| Calculation | 10,000 rows (s) | 100,000 rows (s) |
| --- | ---: | ---: |
| Romps wet bulb | 0.027 | 0.110 |
| Lu Heat Index | 0.018 | 0.177 |
| Explicit bulk (Humidex, Lu, Romps) | 0.031 | 0.292 |
| Automatic bulk (eight methods) | 0.034 | 0.319 |
| Liljegren | 0.215 | 1.132 |

[Raw timing records](v3-3.0.0.csv) include row counts and dependency versions.
These measurements preceded a small allocation reduction in scalar alignment;
use the runner for current timings.

A separate fixed 100,000-row Liljegren comparison used the exact 2.4.0 checkout
at `112f43f` and the v3 canonical function with matched inputs/default controls.
Median times were 1.096 s for 2.4.0 and 1.074 s for v3 after allocation reduction,
a difference within normal timing variation. Missing masks matched and the
maximum absolute WBGT difference was 8.04e-7 C, below the 1e-4 C numerical
comparison tolerance. This is implementation regression evidence, not a claim
of equivalence to the original C model or an empirical accuracy assessment.
